# ⏱️ Python Turtle Stopwatch

A simple graphical stopwatch built using Python's built-in Turtle graphics module. It features interactive start/pause and restart controls, keyboard shortcuts, and a real-time digital display.

## ✨ Features

- ▶️ **Start / Pause:** Start or pause the stopwatch.
- 🔄 **Restart:** Reset the timer to zero.
- ⌨️ **Keyboard Controls:** Use keyboard shortcuts to control the stopwatch.
- 🎨 **Graphical Interface:** A circular design with interactive buttons.
- ⚡ **Automatic Updates:** Refreshes the display every second.

## 🛠️ Technologies Used

- Python 3
- Turtle Graphics
- Time
- Event Handling

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your system. The Turtle module is included with standard Python installations.

### Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Navigate to the project directory:

   ```bash
   cd your-repository
   ```

3. Run the application:

   ```bash
   python stopwatch.py
   ```

## 🎮 Controls

| Action | Control |
|---|---|
| Start / Pause | Green button or `S` key |
| Restart | Orange button or `R` key |
| Exit | `Q` key (if configured) |

*Click inside the Turtle window before using keyboard shortcuts if necessary.*
